## The five knowledge-check sections

`content/chemistry/modules.json` holds **ten** top-level sections, so "5 per section" needs a documented grouping. The one used here:

| group | name | module sections |
|---|---|---|
| S1 | Principles and Structure | `principles-of-chemistry`, `periodic-table-bonding` |
| S2 | Quantitative and Physical Chemistry | `mole-concept`, `energy-changes`, `reaction-kinetics` |
| S3 | Reactions and Aqueous Chemistry | `acids-bases-salts`, `redox-reactions`, `electrolysis` |
| S4 | Organic Chemistry | `organic-chemistry` |
| S5 | Inorganic Chemistry | `inorganic-chemistry` |

The grouping follows the plan's S1/S3/S4/S5 exactly. **S2 is the one refinement:** the plan put `mole-concept` alone in "Quantitative Chemistry", but that module holds only **3 lessons**, so it cannot supply the five DISTINCT topics a section needs. The two other physical-chemistry modules - `energy-changes` and `reaction-kinetics` - join it, giving S2 8 lessons. `electrolysis` (5 lessons) joins S3, the aqueous/ionic reaction group, rather than S1: its content is electrode reactions, not structure.
